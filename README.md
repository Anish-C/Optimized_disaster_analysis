# Optimized Disaster Analysis

GitHub Pages website for a CS 566 project on a vision model that can analyze and classify the severity of disaster damage. Currently tested on Hurricanes.

## 🌐 Live Website

Once GitHub Pages is enabled, the website will be available at:
**https://anish-c.github.io/Optimized_disaster_analysis/**

## 📋 Project Overview

This project presents a vision model designed to analyze and classify the severity of disaster damage using advanced machine learning techniques. The model can automatically assess damage levels from images, providing rapid and objective evaluations critical for emergency response and resource allocation.

## 🚀 Deployment

See [DEPLOYMENT.md](DEPLOYMENT.md) for detailed instructions on how to enable and configure GitHub Pages for this repository.

### Quick Start

1. Go to your repository Settings → Pages
2. Select the branch to deploy (e.g., `main` or current branch)
3. Choose `/ (root)` as the source directory
4. Save and wait for deployment (1-2 minutes)

## 📁 Repository Structure

- `index.html` - Main website page

- `.nojekyll` - Prevents Jekyll processing

